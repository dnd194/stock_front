1. 프로젝트 개요

한국투자증권 OpenAPI를 기반으로 한 주식 데이터 시각화 웹 애플리케이션입니다.
외국인과 기관이 동반 매수한 종목을 분석하여 차트와 리스트 형태로 제공합니다.

  • 목적: 외국인 · 기관 동반 매수 종목 분석 및 시각화
  • 데이터 소스: 한국투자증권 OpenAPI
  • 백엔드 API: http://localhost:3001/market/refined

5. 데이터 흐름

사용자 접속 ↓ app/page.tsx (스플래시 2초) ↓ app/home/page.tsx ↓ fetch("http://localhost:3001/market/refined") ↓ 응답: { success, data: Stock[], message, timestamp } ↓ 데이터 시각화 (차트 + 리스트)

6. 주요 타입 정의

6.1 Stock 타입

type Stock = {
  name: string                    // 종목명
  code: string                    // 종목 코드
  foreignQty: number              // 외국인 수량
  institutionQty: number          // 기관 수량
  foreignAmount: number           // 외국인 매수 금액
  institutionAmount: number       // 기관 매수 금액
  fundAmount: number              // 기금 매수 금액
  totalAmount: number             // 총 매수 금액
}

6.2 MarketRefinedResponse 타입

type MarketRefinedResponse = {
  success: boolean                // 성공 여부
  data: Stock[]                   // 주식 데이터 배열
  message: string                 // 응답 메시지
  timestamp: string               // 타임스탬프 (ISO 형식)
}

7. 주요 특징

  • App Router Next.js 13+ App Router 사용
  • Client Component 클라이언트 컴포넌트 중심 ("use client")
  • Loading State 로딩 상태 관리 (NProgress, Skeleton UI)
  • Responsive Chart 반응형 차트 (Recharts)
  • API Integration 한국투자증권 OpenAPI 연동
  • Type Safety TypeScript로 타입 안정성 확보
